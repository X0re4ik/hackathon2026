# Цель: Последовательная обработка .txt файлов из каталога sources/ (по одному за итерацию)

Ты работаешь в Ralph Loop. Твоя задача на эту итерацию — обработать **ровно один** следующий необработанный `.txt` файл и **немедленно остановиться**.

## Модель работы (одна итерация = один файл)

### 1. Найди следующий необработанный файл
- Просмотри `sources/`, найди `.txt` файл, для которого **нет** `output/meta/META-<имя>.md`.
- Если все файлы уже обработаны → перейди к шагу «Завершение».
- Если файлов для обработки нет вообще → создай `progress/<ITERATION>.done.md` с текстом "нечего обрабатывать" и заверши.

### 2. Запиши план
Создай `progress/<ITERATION>.plan.md`:
```
Файл: sources/<имя>.txt
Действие: извлечение метаданных
```

### 3. Прочитай файл
```
read_file(file_path="sources/<имя>.txt")
```

### 4. Извлеки метаданные
По правилам из AGENTS.md (твой system prompt).

### 5. Сохрани результат
```
write_file(file_path="output/meta/META-<имя>.md", content="<сгенерированный markdown>")
```

### 6. Запиши результат итерации
Создай `progress/<ITERATION>.done.md`:
```
sources/<имя>.txt → ✅ output/meta/META-<имя>.md
```

### 7. ОСТАНОВИСЬ
**НЕ обрабатывай другие файлы.** Ты сделал ровно один файл. Заверши работу.

---

## Завершение (все файлы обработаны)

Если необработанных файлов нет — создай `progress/<ITERATION>.goal_done.md`:
```
Все файлы из sources/ обработаны.
Обработано: X файлов
```
И ОСТАНОВИСЬ.

---

## Правила
- Один файл за итерацию, строго. НЕ пытайся обработать больше одного.
- Пропускай файлы, для которых уже есть `META-<имя>.md` в `output/meta/`.
- Пустые (0 байт) — пропускай, фиксируй в done.md.
- `sources/` — только чтение.
- Выходной каталог `output/meta/` — создай, если не существует.
