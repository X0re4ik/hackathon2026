# Цель: Обработать один мета-файл в свод jobs

Ты работаешь в Ralph Loop. Твоя задача на эту итерацию — обработать **ровно один**
мета-файл интервью: прочитать его, слить jobs в файл свода и **немедленно остановиться**.

---

## Модель работы (одна итерация = одна мета)

### 1. Найди следующий необработанный файл

Просмотри `output/meta/`, найди `META-*.md`, чей `meta_id` **отсутствует** в `sources[]`
файла свода `output/OUTPUT.md`.

- Файла свода нет → все меты не обработаны.
- Все меты уже в `sources[]` → переходи к разделу «Завершение».

`meta_id` возьми из frontmatter меты. Если его нет — возьми имя файла без расширения.
Файл свода — `output/OUTPUT.md`.

### 2. Запиши план

PROGRESS_DIR и номер итерации тебе передал оркестратор в задании.
Создай `<PROGRESS_DIR>/<N>.plan.md`:

```
Файл: output/meta/META-<имя>.md
Действие: слияние одной меты в свод
```

### 3. Прочитай мету

Тебе нужны:

| Поле | Для чего |
|---|---|
| `meta_id` | трассировка и дедупликация |
| `jobs[]` (`id`, `job`, `quote`) | что объединяем |
| `pains[]` | связь с jobs, теги B и D, флаги критичности |
| `segment.type` | фасет `A/segment` |
| `respondent.customer_status` | фасет `A/status` |
| `engagement.engagement_score` | тег группы A |
| `interview_commentary.churn_driver_hypotheses` | флаг `churn-driver` |
| `source.reference` | ссылка на первоисточник |

### 4. Свяжи боли с jobs

Если у болей есть `related_jobs` — используй его.
Если нет — свяжи сам по смыслу: боль относится к job, если мешает его выполнению.

Боль без job → в `## Боли вне jobs`. Не выдумывай job ради боли.

### 5. Прочитай таблицу тем

Прочитай файл свода от начала до первого `## T-`. Дальше не читай.

### 6. Реши по каждому job

Для каждого job из меты, по правилам слияния (AGENTS.md → Правило 2):

**A. Нашлась подходящая тема** → прочитай её секцию. Добавь участника. Обобщи
формулировку, если стала узкой. Добавь новые теги. Обнови строку в таблице тем.

**B. Подходящей темы нет** → создай новую тему: строка в таблице + секция.
ID = следующий по порядку. Каноническая формулировка = job из меты.

### 7. Пересчитай доли и флаги

Только по данным открытой секции (Правило 1):

1. **Доли фасетов** — строка `**Доли:**` (AGENTS.md → Фасеты и доли).
2. **Флаги критичности** — строка `**Сигналы:**` (AGENTS.md → Флаги критичности).
   Без суммы: балл считается на финализации. Ни один не сработал — пиши `—`.
3. **Причина ухода** — если гипотеза относится к теме, добавь строку с `meta_id`,
   статусом и дословной цитатой.

### 8. Запиши

1. Обнови таблицу «Темы».
2. Обнови или добавь секции тем.
3. Добавь боли без jobs в `## Боли вне jobs`.
4. Добавь новые теги C в `tag_definitions` — с определением и `kind`.
5. Добавь запись в `sources[]`.
6. Обнови список интервью в заголовке `# Свод jobs`.

Разделы `## Облако тегов` и `## Критичность` не трогай.

### 9. Запиши результат итерации

Создай `<PROGRESS_DIR>/<N>.done.md`:

```
output/meta/META-<имя>.md → ✅ свод обновлён
```

### 10. ОСТАНОВИСЬ

Выдай отчёт на четыре строки:

```
META-XXX: N jobs → T-NN (участник), T-MM (новая тема)
болей: N привязано, N в «Боли вне jobs»
новых тегов C: ... (...)
причина ухода: T-NN ← «цитата»
```

**НЕ обрабатывай другие файлы.** Ты сделал ровно один файл. Заверши работу.

## Завершение (все файлы обработаны)

Если ты получил задачу «выполни финализацию», а не «обработай файл»:

1. Прочитай `finalization.md` (рядом с этим файлом).
2. Выполни его по шагам.
3. Создай `progress/merge/goal_done.md`.

И ОСТАНОВИСЬ.

---

## Правила

- Одна мета за итерацию, строго. НЕ пытайся обработать больше одной.
- Правило 0 (читать минимум) — обязательно.
- Разделы «Облако тегов» и «Критичность» в цикле не трогать.
- Свод растёт инкрементально, не пересобирается с нуля.
- AGENTS.md — полные правила по тегам, фасетам, флагам и формату.
