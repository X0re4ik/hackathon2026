# INT-T-001 — проектный менеджер, active

## Резюме

Респондент — проектный менеджер, систематизатор, ведущий бюджет в Excel. Перешла из другого банка по рекомендации коллеги из-за обещаний удобной аналитики расходов, разбивки по категориям и графиков. Ожидала, что приложение заменит Excel для повседневного контроля бюджета.

Реальность оказалась截然不同: аналитика не работает корректно (ошибочные MCC-коды, отсутствие ручного переназначения категорий, ограниченные периоды), автоплатежи не срабатывают стабильно, есть критическая проблема доверия — данные в приложении не совпадают с данными банка. Пользователь вернулась в старый банк, несмотря на устаревший интерфейс, потому что там стабильность и честность данных важнее красивых анимаций.

## Комментарий агента

Судя по тексту, респондент — высокововлечённый пользователь (engagement_score: 7), активно использующий продвинутые функции банка (автоплатежи, виртуальные карты, оспаривание транзакций). Однако именно высокий уровень вовлечённости делает проблемы особенно критичными: она построила финансовые процессы вокруг этого банка и столкнулась с системными дефектами.

Наиболее тревожный сигнал — multiple trust_breach incidents (p4, p5, p8). Для банка это критичнее, чем любые UX-фрiction: если пользователь не верит, что баланс на экране соответствует реальному счёту, продукт теряет базовое назначение.

Возможно, продукт ориентирован на массового пользователя с низким уровнем вовлечённости, для которого «красивая картинка» аналитики достаточно хороша. Для аналитического сегмента (проектные менеджеры, финансовые специалисты) — продукт не подходит.
